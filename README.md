Student Data Organizer

📌 Project Description

Student Data Organizer is a Python-based console application used to manage student information. It allows users to add, display, update, and delete student records. It also displays the subjects offered by the students.

This project demonstrates the use of lists, dictionaries, tuples, sets, loops, conditional statements, match-case, and user input in Python.

✨ Features

- Add a new student
- Display all student information
- Update student information
- Delete a student record
- Display subjects offered
- Exit the program
- Menu-driven console interface

🛠️ Technologies Used

- Programming Language: Python
- Concepts Used:
  - Lists
  - Dictionaries
  - Tuples
  - Sets
  - "while" loop
  - "for" loop
  - "if-else" statements
  - "match-case"
  - User input
  - String methods
  - Formatted output

📂 Student Information Stored

The program stores the following details:

- Student ID
- Name
- Age
- Grade
- Date of Birth
- Subjects

The Student ID and Date of Birth are combined into a tuple and used as the student's identity.

▶️ How to Run

1. Install Python on your computer.
2. Save the program as:

student_data_organizer.py

3. Open the terminal or command prompt.
4. Run the program using:

python student_data_organizer.py

5. Select an option from the menu.

📋 Menu Options

1. Add Student
2. Display All Students
3. Update Student Information
4. Delete Student
5. Display Subjects Offered
6. Exit
